# Preparação do Repositório pelo Professor

> Checklist para publicar o template corretamente antes de disponibilizá-lo para os alunos.

## Para que serve

Use este documento para evitar que links, permissões e configurações fiquem incompletos antes do repositório ser compartilhado com a turma.

Antes de publicar este template para a turma, revise:

1. `README.md` → substituir:
   - `INSERIR_LINK_PPT_AULA_01`
   - `INSERIR_LINK_PPT_AULA_02`
   - `INSERIR_LINK_NOTION_DISCIPLINA`
   - `@USUARIO_DO_PROFESSOR`
2. Confirmar se o repositório está **Public**;
3. Opcionalmente marcar o repositório como **Template repository** além de permitir Forks;
4. Verificar se Issues estão habilitadas;
5. Criar/confirmar labels usadas pelos templates: `bug`, `enhancement`, `documentation`;
6. Testar o clone dentro do `C:\xampp\htdocs`;
7. Iniciar Apache e validar a Home do template.
