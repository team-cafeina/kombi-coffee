# CleanSchedule — Serviços de Limpeza

## Sobre

Sistema para gerenciamento de serviços de limpeza residencial, permitindo registrar clientes, tipos de serviço e solicitações.

## Público-alvo

- Clientes;
- Equipe administrativa;
- Prestadores de serviço.

## Requisitos técnicos

- Login via MySQL;
- Área administrativa protegida;
- CRUD de serviços;
- Relacionamento entre clientes e solicitações;
- Interface responsiva com Bootstrap.

## Execução local

Utilizar XAMPP com Apache e MySQL ativos.
