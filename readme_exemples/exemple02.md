# PetCare — Gestão de Serviços para Pet Shop

## Objetivo

Organizar clientes, pets, serviços e atendimentos em uma única aplicação web.

## Funcionalidades previstas

- Autenticação;
- CRUD de pets;
- CRUD de serviços;
- Registro de atendimentos;
- Dashboard administrativo.

## Estrutura de dados

```text
clientes (1) ---- (N) pets
pets     (1) ---- (N) atendimentos
servicos (1) ---- (N) atendimentos
```

## Stack

PHP puro + MySQL + HTML + CSS + Bootstrap + XAMPP.
