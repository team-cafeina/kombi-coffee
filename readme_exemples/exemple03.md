# FixNow — Assistência Técnica

## Problema

Clientes precisam acompanhar solicitações de manutenção enquanto a equipe precisa registrar status, equipamentos e serviços realizados.

## Principais páginas

- Home;
- Login;
- Abertura de solicitação;
- Consulta de status;
- Área administrativa;
- Gerenciamento de ordens de serviço.

## CRUD principal

Ordens de Serviço:

- Create;
- Read;
- Update;
- Delete.
