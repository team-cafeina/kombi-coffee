# Exemplo — Feature Request

> Use este arquivo como base para abrir uma Issue de funcionalidade no GitHub.

## [FEATURE] Cadastro de serviços na área administrativa

### Contexto

O administrador precisa cadastrar os serviços oferecidos pela empresa sem alterar diretamente o banco de dados.

### Objetivo

Criar uma tela na área administrativa para cadastrar novos serviços.

### Escopo

- Formulário com nome, descrição, preço e status;
- Validação dos campos obrigatórios;
- Persistência dos dados no MySQL utilizando PHP;
- Mensagem de sucesso ou erro;
- Listagem atualizada após o cadastro.

### Critérios de aceitação

- [ ] Usuário não autenticado não acessa a página;
- [ ] Serviço válido é salvo no banco;
- [ ] Campos obrigatórios são validados;
- [ ] Interface segue o Figma;
- [ ] Fluxo foi testado no XAMPP.
